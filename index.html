📚 How It Works

🎯 Password: 1011

Set switches: A=1, B=0, C=1, D=1 to unlock the gate!

🔧 Components Used (Hardware)

  • 74HC04 — NOT Gate IC
  • 74HC08 — AND Gate IC
  • 4x Slide Switches (A, B, C, D)
  • Green + Red LEDs
  • BC547 Transistor (Motor Driver)
  • DC Motor (opens gate)
  • 1N4007 Diode (spike protection)
  • Resistors (330Ω, 1kΩ, 10kΩ)

⚙️ Logic Flow

1. Switches give binary input (A, B, C, D)

2. NOT gate inverts B → B'

3. Three AND gates combine: (A·B') · (C·D)

4. If MATCH = 1 → Green LED + Motor ON → Door Opens

5. If MATCH = 0 → Red LED ON → Door stays locked
